## Projeto final

O projeto final da disciplina consiste em testar uma hipótese evolutiva utilizando
métodos filogenéticos comparativos. Os estudantes poderão testar uma hipótese 
de interesse pessoal a partir dos seus próprios dados, ou testar uma hipótese 
pré-formulada a partir de dados disponíveis neste repositório. Em ambos casos, 
os estudantes deverão apresentar os scripts utilizados em sala de aula, devendo:

 - Explicar a hipótese evolutiva que foi testada;
 - Justificar os métodos utilizados;
 - Explicitar os padrões esperados que confirmariam a hipótese (expectativas);
 - Explicitar os padrões obtidos com a aplicação dos métodos (resultados);
 - Interpretar os padrões obtidos de forma biológica (discussão);

Outros pontos podem ser apresentados e compartilhados, tais como dificuldades 
técnicas ou dúvidas teóricas. É opcional o preparo de *slides* ou outras ferramentas
que auxiliam na apresentação.
